# DSA Practice Catalog — Other OJs & Supplements

Danh sách website ngoài Codeforces và các bài bổ sung để luyện cùng pattern. **Không loại bài trùng dạng**: các bài tương tự trên nhiều OJ được giữ riêng để có thêm lượt luyện.

- **[PDF]**: bài/link có trong tài liệu gốc.
- **[Bổ sung]**: bài được thêm để tìm link cụ thể cho một chủ đề hoặc luyện thêm trên OJ khác.
- LuyenCode URLs được giữ theo URL trong PDF; nếu trang đổi đường dẫn hoặc yêu cầu đăng nhập, tìm bằng mã bài.

# 5. Thứ tự ôn gợi ý

1. **Foundations & Math:** LuyenCode cơ bản → Codeforces Math → CSES Number Theory.
2. **Array / Sorting / Two Pointers:** LuyenCode mảng → Codeforces sorting/two pointers → InterviewBit.
3. **String:** LuyenCode string → Codeforces string → CSES Word Combinations.
4. **Prefix Sum / Sliding Window:** Codeforces Prefix/Difference → CSES Sliding Window Sum → GFG Minimum Swaps.
5. **Recursion / Backtracking:** Sinh nhị phân → Gray Code → Creating Strings → Apple Division.
6. **Dynamic Programming:** Grid Traveler / Can Sum → CSES Dice Combinations / Minimizing Coins → AtCoder DP A–D, K, Z.
7. **Data Structures:** RMQSQ → Nearest Smaller Values → INVCNT → Dynamic Range Minimum Queries.
8. **Graph / Tree:** Counting Rooms → Building Roads → LCASQ.
